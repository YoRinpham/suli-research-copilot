# 溯理 SULI：研究手稿室

## 已确认的设计

2026-10-18 确认正式产品名称为「溯理」，英文标识 `SULI`，前端统一展示「溯理 SULI」。名称对应追溯证据来源、梳理线索与推演假设；适用于首页、工作区、使用指引、页脚、浏览器标题和基准展示。首页左上角品牌采用纯文字标识，移除绿叶插图。首页文案、科学对象、人工权限与来源链保持原有含义。

项目首页与完整研究工作区采用纸白与墨绿的「研究手稿室」。固定阅读结构、清楚的阶段与真实来源是基础，灵性来自字体、留白、引用与页边排版。首页采用用户确认的「纸上山海」插图：纸页折叠为山地、纸层转为等高线，一条墨绿路径贯穿纸面，寓意可追溯的研究方向。不使用自由拖拽、散乱便签或知识图谱。

本轮以桌面端为交付和验收目标。按用户最新要求，手机端页面暂不纳入；现有基础自适应样式保留，不继续扩展移动端设计。

- 纸白 `#FDFCF8`、浅暖灰 `#F1F0E9`、墨绿 `#397157`、深墨色 `#293932`、鼠尾草绿 `#A9B8A2`、分隔线 `#E0E2D7`。
- 首页主文案与引导语使用用户选择的 E「辰宇落雁体 2.0 Thin」字形。原字体缺少部分简体字，因此两句固定装饰文案沿用确认样张中的繁体写法，并标注 `lang="zh-Hant"`；其余界面仍为简体。以本地 WOFF 子集加载，保留 OFL 授权，子集重命名为 Research Manuscript Hand；不把繁体字形映射到简体码位，不使用该子集渲染用户内容。其余标题、摘录与重要科学文本使用宋体类系统字体，正文、表单与操作使用无衬线系统字体。不依赖在线字体或分发系统字体文件。
- 桌面整体最大 1440px，正文最多约 760px，页边来源最多约 280px；小屏保留单列正文。
- 主要内容以章节、分隔线、引文和脚注组织。表单和统计保留明确结构，完整评估及诊断按需展开。

## 页面与阶段

首页是研究项目目录，展示真实项目标题、研究问题和更新时间。新建入口展开表单，首次使用引导填写研究问题，提交失败保留输入。

首页「從一個值得追問的問題開始」放大为 28px，主标题上限 72px，以适配所选字体较小的字面；移除原说明行。右侧「纸上山海」采用用户确认的线稿修订版：细鼠尾草绿山形与等高线、加深的连续墨绿研究路径，以及向前延展并轻微卷曲的纸页；去除纸雕的色块和阴影，保持纸白背景。仅作装饰，不展示模拟科学结果。图像由内置 imagegen 生成，确认后保存于 `frontend/public/images/paper-landscape-lineart.png`，通过 Next Image 提供自适应资源。插图沿用预览的 `448px` flex 基准、`40%` 宽度、`42%` 上限与 `32px` 右边距；首页引导区最小高度 `430px`。「研究中的问题」使用浅绿底目录栏、无衬线栏目标题，与下方宋体项目名区分；长项目名最多显示两行，完整名称保留在链接文本和标题提示中。

首页文字链接「使用指引」进入静态 `/guide` 页面。页面以五阶段横向链总览和阶段内纵向操作链说明完整过程，覆盖研究问题、PDF 索引、检索、证据、主张、全景、空白、假设、计划、数据分析与报告；点击阶段可跳至对应章节。人工选择、审核与执行节点单独标明。教程不发起 API 请求，也不触发科研状态变化。

项目入口保持 `/projects/[id]`，查询参数 `stage` 取值如下：

- `literature`：论文原文、检索候选、已保存证据。
- `landscape`：科学主张、人工依据判断、研究全景及冲突。
- `directions`：候选研究空白、可检验假设。
- `experiment`：实验计划、CSV 数据、清洗审核、确定性统计、图表、解释。
- `report`：报告阅读、审核、修订、历史、来源与导出。

默认或未知 stage 进入文献。章节目录和对象锚点可以直接打开、刷新，支持浏览器前进和后退。已有 `#claim-*`、`#evidence-*`、`#landscape-item-*`、`#gap-*`、`#hypothesis-*` 等来源锚点优先打开其所属阶段。

插画保留原始 PNG，由 Next Image 以 `unoptimized` 展示，避免有损压缩在浅底与细线周围产生块状色差，保持确认样张的线条与底色。

## 状态与科学权限

阶段切换只改变阅读位置，不触发生成、选择、接受、执行或导出。首次访问后，阶段组件留在当前项目中；研究方向和实验计划共享原有 M4 状态。切换阶段不清除检索候选、修订草稿、数据配置或进行中的操作。

初次加载和重新进入阶段读取服务端最新列表。后台读取不会卸载已加载的工作区；使用请求序号拒绝过时读取，并在写操作开始与结束时使旧快照失效。返回报告时保持正在编辑的标题、叙述及所选历史版本。只有成功生成/保存报告新版本时才主动切换到新版本；预览与审核不清除未提交编辑。

草稿只在当前打开项目内保留，完整刷新或离开项目不提供额外本地持久化。

所有人工依据判断、选择、接受、拒绝、修订与执行仍调用现有独立 API。旧版本、限定范围、不确定性、服务端资格与正式导出门槛不变。

## 页边来源

科学对象的来源入口打开页边核查，分别呈现支持、质疑或启发角色、关联主张、完整 Evidence 原文、实际文件和 PDF 物理页码。报告使用自己保存的来源快照。缺失来源明确提示，不补造原文或引用。

跨阶段来源定位会切换所属阶段，等待目标数据加载，展开目标所在的折叠内容，然后滚动并聚焦对象。原始文件仍通过已有文件端点与 `#page=N` 打开；不新增 PDF 渲染器或高亮定位。

980px 以下，来源以可关闭面板显示；面板支持 Escape、键盘焦点循环及关闭后的焦点恢复，并锁定背景滚动。桌面保持正文与来源并排。按钮不依赖悬停。

统计值使用同一个只读指标表展示，不舍入、重算或由 AI 改写；实验阶段仍可展开原始计算记录。

## 实现边界与验证

沿用 Next.js、React、TypeScript、现有 API 客户端与系统字体，新增本地 OFL 手写标题字体子集及插图资源，无新运行依赖，无后端或数据库契约变更。已有未提交的科学逻辑修复继续保留。

验证命令（在 frontend 目录）：`npm test`、`npx tsc --noEmit`、`npm run build`。行为测试覆盖 stage 解析、跨阶段锚点、查询参数保留、无效 hash、报告编辑保留及写操作与迟到读取之间的竞态。

浏览器验收以桌面排版、阶段导航与历史、来源定位、草稿保留、修订重置、来源失效和导出门槛为准。小屏基础回退不作为本轮交付要求。合成测试环境不替代 PostgreSQL/pgvector 与真实 Qwen 验证。
