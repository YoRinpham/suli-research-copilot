# 溯理 SULI 比赛提交说明

**产品名称：溯理（SULI）。产品定位：从可追溯证据到可检验实验的科研工作台。** Qwen 用嵌入模型检索论文，用 `qwen3.8-max` 生成结构化科学候选与谨慎叙述。来源链、确定性统计和显式人工审核阻止模型文本直接变成科学事实。系统辅助研究者思考，不进行自主科学发现。

## 对照评审标准

| 维度 | 已实现证据 |
| --- | --- |
| 具体瓶颈 | 论文段落到可核查证据、实验与报告之间的跨阶段搬运及误引风险 |
| 多阶段工作流 | PDF → Evidence/Claim → Landscape/Gap/Hypothesis/Plan → Dataset/Analysis → Interpretation/Report |
| 真实数据流 | 原始 PDF 物理页与不可变 CSV 版本，确定性 StatisticalResult 与 FigureArtifact |
| 人的介入 | Evidence 选择、科学对象审核、清洗/分析批准、解释和报告接受 |
| 可测量效率 | m6-v1 同场景真实计时与 JSON/Markdown 结果；人工基线未测量时不宣称提升 |
| 可复用架构 | LLM/Embedding Provider 分离、明确的领域对象、版本化提示与来源快照 |
| 创新点 | 报告同时绑定文献物理页、数值执行链、图表与人工科学权限 |

## 技术回答速查

- **如何防止假引文？** 模型只返回叙述和经白名单校验的 `source_refs`；可见来源令牌、标题、页码由服务器按 Paper、Evidence、PaperChunk 的保存记录确定性呈现。叙述中的伪造来源令牌会被拒绝，报告仍须人工接受。这是结构性防护，不保证所有科学语义判断正确。
- **为何不让模型算统计？** 数值由白名单 SciPy/NumPy 计算并存为 StatisticalResult，报告直接读取该记录，避免文字模型改写 p 值。
- **如何证明来源？** Report Source Bundle 含确切 ID、源状态和哈希，可下钻到 Claim/Evidence/PaperChunk/Paper/物理页以及 AnalysisRun/DatasetVersion/FigureArtifact。
- **AI 能自动接受结论吗？** 不能。Gap/Hypothesis 是人选，Plan/Interpretation/Report 是人审核；模型输出默认为待审。
- **Qwen 失败怎么办？** 失败 Run 可诊断、无半成品报告；保留已有合格结果及确定性导出，有限重试。
- **效率如何测量？** 固定场景与输入哈希，人工和 溯理分别记录真实阶段墙钟时间，只有两方完成且一致才计算差值。
- **跨领域可复用什么？** 证据来源链、Provider 接口、审核门槛、版本化结果与导出机制；统计方法目录目前有意狭窄。
- **“新研究空白”是什么意思？** 仅在已上传、已检查的文献集合内的候选空白，不是全领域新颖性保证。

## 真实限制

合成演示 PDF/CSV 只用于流程验证。AI 科学判断可能错误，研究者需审核。没有全球新颖性搜索、自动实验执行或任意统计代码；因果解释受研究设计限制。现场 Qwen 生成依赖服务和网络。效率百分比取决于同一协议下的真实人工基线；当前未测量，不作提升声明。自动测试证明结构与计算约束，科学叙述质量仍需独立人工评估。
