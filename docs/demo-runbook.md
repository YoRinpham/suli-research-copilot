# 溯理 SULI · M6 比赛演示运行手册

## 演示前

1. 按 README 启动 PostgreSQL、迁移到 `0010_m6_report_delivery`、后端和前端。运行 `python evaluation/m6_preflight.py --network --http`（在 `backend` 目录，使用虚拟环境 Python）。检查 DB、迁移、pgvector、存储、前后端 HTTP 及配置状态。可显式加 `--provider-smoke` 执行**一次**合成微型 Qwen 请求。
2. 使用 `backend/evaluation/assets/` 下的两篇合成 PDF 和 `synthetic_scores.csv`；核对 `m6_scenario.json` 中的 SHA-256。所有演示内容显著称为“合成示例”。这些 PDF 由本仓库脚本生成，避免第三方版权问题。
3. 提前建好一个已完成的演示项目并逐页核查来源；现场的三分钟故事主要展示已有合格对象及一两个可控操作。不要假设现场网络能在三分钟内完成所有 Qwen 阶段。记录项目 ID、报告 ID 和一条明确的 Evidence 来源页。
4. 准备一份完整已接受报告的 Markdown/HTML 导出作为 provider 故障时的可检查备份。故障时不复制伪造输出，也不自动接受草稿。

## 可重复建立项目

研究问题设为“在两篇合成训练方法文献中，方法 A 与 B 的结果比较有何局限，如何设计可证伪的比较？”依次上传、索引两篇 PDF，检索并明确选择含方法/局限的 Evidence；生成并人工审核 Claim 与 Landscape；限定语料选择 Gap、Hypothesis、ExperimentPlan。上传合成 CSV，审查画像；如果不需清洗，直接使用原始 DatasetVersion。建议分析使用 `welch_t`，明确列映射 `group`/`score` 与组值 A/B，人工批准后执行。用实际结果创建组别图，生成并人工审核 ResultInterpretation。最后选择该已接受解释生成报告草稿，核查来源页、数字、图表、限定措辞，人工接受并导出。每个 Qwen 阶段保留失败记录；失败时查看既有对象，再在网络恢复后有限重试。

## 三分钟演示脚本

新版界面从项目目录进入，顶部依次为「文献 / 研究全景 / 研究方向 / 实验 / 报告」。文献阶段保留上传、索引、检索与证据；科学主张在研究全景阶段。空白与假设位于研究方向，实验计划与 CSV、统计、图表、解释位于实验阶段。切换阶段不会自动推进科学决定。

首次使用时可点击首页右上角「使用指引」，进入 `/guide` 查看链式操作教程；顶部阶段链可跳至相应操作节点，人工选择与审核步骤均有标注。教程独立于项目数据加载。

点击「核查来源」或文献来源脚注，在页边并排阅读原文与 PDF 页码；点击「查看证据记录」或关联主张，定位对应阶段。手机端来源面板可用关闭按钮或 Escape 退出。报告修订默认待审核，最终导出仍要求服务端当前资格与人工接受。阶段链接可直接打开，例如 `/projects/<id>?stage=report`。

1. **问题**：研究者从论文到实验报告要反复搬运证据、核算结果并防止误引。
2. **证据**：打开一张 Claim/Gap 卡，沿 Evidence 链点开原始 PDF 物理页，说明模型不能凭空发明页码。
3. **人的决定**：展示 Gap、Hypothesis、Plan 与解释的审核状态。明确“所提供文献内的候选空白”，不声称全球首创。
4. **真实数据流**：展示合成 CSV、人工批准的分析方案、StatisticalResult 数值表和服务器生成图表。说明统计由确定性代码而非 Qwen 计算。
5. **报告**：打开待审/已接受报告，展示 Qwen 叙述与确定性数值和引文分层；进入原始页，展示 Markdown/HTML 导出。
6. **效率**：仅展示真实会话的基准输出。如果人工基线尚未测量，明确显示 `NOT MEASURED`，不讲节省百分比。

## 故障处置与网络 A/B

预检 `BLOCKED` 时先处理 DB/迁移/存储；`DEGRADED` 时已接受报告仍可查看和导出。`provider_timeout`、连接、协议错误和格式失败都有失败 GenerationRun；保留既有科学对象并在状态清楚后再试。不要无限刷新或反复点生成。可用同一微型 `--provider-smoke` 请求分别测 VPN/代理路径与允许的直连或分流路径，记录条件、provider 主机名、是否收到 HTTP 响应、成功与耗时、匿名化失败类别。环境变量只能说明代理配置，不能证明操作系统/VPN/TUN 的实际路由；不自动更改系统网络。操作前确认分流符合所在网络规则。现场长模型阶段显示进度，必要时切换到已完成项目讲解。
