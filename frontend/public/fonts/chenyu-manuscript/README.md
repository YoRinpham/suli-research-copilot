# Homepage manuscript handwriting

Source: [ChenYuluoyan 2.0 Thin](https://github.com/Chenyu-otf/chenyuluoyan_thin),
by Chenyu and Wei Chen. Licensed under SIL Open Font License 1.1; see `OFL.txt`.

`headline.woff` is a renamed, unhinted subset for the two fixed homepage lines.
Its family name is **Research Manuscript Hand**. No outlines were synthesized,
borrowed or remapped between simplified and traditional characters.

The homepage uses the traditional text approved in font candidate E:

> 從一個值得追問的問題開始
>
> 每一項研究，都有它的來處。

All other application text keeps its existing fonts and orthography. If these
two lines change, rebuild the subset from the original font and check coverage;
do not apply this subset to project titles or user-provided scientific text.
